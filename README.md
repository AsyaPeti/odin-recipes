# odin-recipes
This is an educational project designed to review the HTML skills learned thus far. It will also serve as a template for future lessons.
The website consists of a main page that links to several recipes.

Skills applied to the project include training muscle memory for writing boilerplate, organizing text using the &lt;h1-h6&gt; and &lt;p&gt; elements, creating ordered and unordered lists using the &lt;ul&gt;, &lt;ol&gt;, and &lt;li&gt; elements, and adding links to other pages and images using the &lt;a&gt; and &lt;img&gt; elements.
New elements were learned specially for this project: &lt;figure&gt; and &lt;figcaption&gt; to place credits directly under an image.

Additionally, trained the skill of working with Git, GitHub, and writing commit messages.
Messed up the articles in commit messages; should be more careful in the future.

Overall, the project is quite simple and straightforward.
